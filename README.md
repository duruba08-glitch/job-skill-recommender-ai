# 💼 Job Recommendation System using AI, SQL, Python, React & Node.js
This system recommends the most relevant job roles based on user skills using an AI-powered full-stack integration.  

## ⚙️ Tech Stack
- **Frontend:** React  
- **Backend:** Node.js + Express  
- **AI Module:** Python (TF-IDF + Cosine Similarity)  
- **Database:** MySQL / Oracle SQL  

## 🚀 Features
✅ Users can input their skills  
✅ AI recommends the top-matching jobs using Cosine Similarity  
✅ Full-stack integration (React → Node.js → Python → SQL)  
✅ Real-time job recommendations  

## 🧑‍💻 How to Run

### 🧩 Backend
```bash
cd backend
npm install
node server.js
```

🧠 AI Module
```bash
cd ai_module
pip install -r requirements.txt
python recommender.py
```

💻 Frontend
```bash
cd frontend
npm install
npm start
```
